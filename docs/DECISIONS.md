## D-026 Phase 2 점수 범위 명시

- 상태: 승인
- 결정일: 2026-07-29
- 결정: 이번 Phase에서 계산 가능한 배당·재무·밸류에이션 70점 구성은

  투자매력이나 최종 추천이라고 부르지 않는다.

  `individual_entry_score`로 분리하고 전체 `entry_score`는 NULL로 유지한다.
- 근거: 현재 Phase의 설명 가능한 상대 척도는 제공하되 미구현 구성요소를
  암묵적 0점이나 임의 추정값으로 포함하지 않기 위함이다.

## D-027 산업 비교와 음수 PER

- 상태: 승인
- 결정일: 2026-07-29
- 결정: 산업 PER/PBR은 양수 유효 표본만 사용하고 IQR 방식으로 극단값을
  완화한다. 세부 산업 표본이 설정 최소값 미만이면 상위 산업으로 fallback하고,
  상위 산업도 부족하면 비교 불가로 처리한다.
- 결정: 현재 PER 또는 PBR이 0 이하이면 `N/M`으로 표시하고 저평가
