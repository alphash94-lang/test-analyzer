# Phase 3 시장충격·시장국면 규칙

- 현재 규칙 버전: `phase3-rule-v2`

## 입력 게이트

- KOSPI 고점과 낙폭은 KRX `KOSPI 시리즈 일별시세정보`의 저장된 실제
  `IDX_NM` 시계열만 사용한다.
- 종목 수익률, 시장 폭, 이동평균은 하나의 가격 provider에서 수집되고
  `is_adjusted=True`, `adjustment_status=VERIFIED`인 행만 사용한다.
- 반도체 구성종목은 설정된 공식 산업분류 체계와 정확한 코드로만 정한다.
  `SECT_TP_NM`, 종목명, 종목코드 패턴은 사용하지 않는다.
- 공식 반도체 지수가 없으면 공식 산업분류 구성종목의 시가총액가중·
  동일가중 결과를 `SELF_CALCULATED_PROXY`로 표시한다.
- 공식 반도체 지수는 KOSPI 수익률 계산 구간의 시작·종료 거래일이 모두
  정확히 일치할 때만 사용한다. 날짜가 어긋나면 공식 산업분류 자체
  프록시로 보수적으로 fallback하고, 그것도 없으면 계산하지 않는다.
- 종목 수익률과 지수 입력은 `PREVIOUS_CLOSE`로 확인된 확정 종가만
  사용한다. 실시간·지연·시세구분 불명 자료를 확정 종가와 섞지 않는다.
- 바스켓과 기여도 시가총액은 KRX 일별매매정보의 동일 거래일 값만
  사용하며 수정가격 원천 행의 미확인 시가총액으로 대체하지 않는다.
- 가격 또는 산업분류 구성종목 커버리지가
  `PHASE3_MINIMUM_CONSTITUENT_COVERAGE`보다 낮으면 시장 폭과
  반도체 분류를 확정하지 않는다.
- 배당주 바스켓은 분석 기준일 이전 OpenDART 공시에서 동일 사업연도·
  주식종류의 최신 정정본에 확정 DPS가 확인된 종목만 포함한다.
  추정 DPS와 최신 정정본에서 0으로 정정된 DPS는 사용하지 않는다.

## 시장충격 분류

- 반도체 주도 조건:
  - 반도체 음의 설명 기여도 비중이 설정 기준 이상
  - 반도체 수익률과 비반도체 동일가중 수익률 차이가 설정 기준 이하
- 시장 전반 투매 조건:
  - 하락 종목 비율이 설정 기준 이상
  - 종목 중앙수익률이 설정 기준 이하
  - 비반도체 동일가중 수익률이 음수
- 두 조건을 모두 충족하면 `MIXED`, 하나만 충족하면 각각
  `SEMICONDUCTOR_LED`, `BROAD_SELLOFF`다.
- 시장이 하락하지 않았거나 입력이 부족하거나 어느 기준도 명확하지 않으면
  `UNCERTAIN`이다.

설명 기여도는 `전일 시가총액 비중 × 당일 종목 수익률`이다. 공식 KOSPI
지수 포인트 기여도나 인과관계가 아니다.
분모는 가격과 KRX 시가총액이 확인된 전체 비교 유니버스이며,
산업분류가 없는 종목도 `미분류` 상태로 기여도에 보존한다.

## 시장국면

- 적색: 252거래일 고점 대비 낙폭과 상승종목 비율이 설정된 투매 기준 충족
- 주황: 적색·황색·녹색은 아니지만 설정 기간 내 신저가 중단 조건 충족
- 황색: KOSPI 단기선 회복, 반도체 회복, 비반도체 시장 확산,
  배당주 상대강도 회복을 모두 확인
- 녹색: 황색 조건에 더해 KOSPI 60일선, 20일선·60일선 위 종목 비율의
  강화 기준을 모두 충족
- 입력이 부족하거나 어느 국면 규칙도 충족하지 않으면 `UNCERTAIN`

삼성전자와 SK하이닉스의 상승은 반도체 회복 입력의 일부일 뿐이다.
비반도체 시장 확산과 배당주 상대강도가 없으면 황색·녹색이 될 수 없다.

## 데이터 신뢰도

- KOSPI 지수 이력 30%
- 수정가격 구성종목 커버리지 30%
- 공식 산업분류 커버리지 25%
- 확정 DPS 배당주 최소 표본 15%

신뢰도는 수익 확률이 아니다. 모든 결과에는 규칙 버전과 입력 해시를
저장하며, 화면의 주요 숫자에는 출처·기준시각·수집시각·계산방법·
데이터 품질·공식 지수 또는 자체 프록시 여부를 함께 표시한다.
입력 해시는 이동평균 전체 가격 이력, 공식 반도체 지수, 구성종목과
분류·배당 상태, 원천과 수집시각, 모든 Phase 3 계산 설정을 포함한다.
