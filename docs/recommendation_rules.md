# Phase 4 추천·포트폴리오 규칙

현재 규칙 버전은 `phase4-rule-v2`다.

## 입력 게이트

- 기준시각 이전에 수집된 활성 KOSPI 종목만 전체 유니버스로 조회한다.
- 각 종목은 같은 기준시각으로 Phase 2 강제필터와 점수를 다시 계산한다.
- 강제필터 `FAIL`은 `투자배제`, `MISSING`·`REVIEW_REQUIRED`는
  `데이터 부족`이며 점수로 상쇄하지 않는다.
- Phase 3가 `AVAILABLE`이 아니거나 종목·시장 중 보수적인 데이터 신뢰도가
  설정 최소값보다 낮으면 추천하지 않는다.
- 공식 산업분류를 확인할 수 없으면 산업 한도를 검증할 수 없으므로
  포트폴리오 배분을 만들지 않는다.

## 점수 범위

- 투자매력은 기존 `PHASE2_CORE_ONLY` 범위를 전체 점수처럼 바꾸지 않는다.
- 진입준비는 현재 확인 가능한 시장국면 25, 반도체 회복 20,
  비반도체 시장 확산 20, 개별 종목 20의 합 85만 계산한다.
- 미구현 Phase 5 수급 15는 0점으로 채우지 않는다.
- 85점 범위를 `PHASE4_NO_FLOW_ENTRY_85`라는 범위명으로 100점 척도에
  정규화한다.

## 추천 그룹

- 회복 준비 완료: 강제필터 통과, 핵심 투자매력·진입준비·신뢰도 기준 충족
- 우량하지만 관망: 투자매력은 회복 준비 기준 이상이나 진입준비 미달
- 과도할인 후보: 같은 Phase 3 기간의 비반도체 동일가중 수익률보다 종목
  수익률이 설정 기준 이상 낮고, 투자매력 기준을 충족하지만 진입준비가 낮음
- 일반 검토: 강제필터와 신뢰도 게이트를 통과하고 일반 검토 점수 이상
- 투자배제: 강제필터 실패 또는 설정된 최소 점수 미달
- 데이터 부족: 핵심 입력·산업분류·시장국면·신뢰도·진입점수 계산 불가

과도할인 후보는 숨은 기업 고유 악재 확인 전 목표비중과 1차 가능비중을
주지 않는다. 상대수익률 차이는 시장이 하락 원인이라는 인과 증거가 아니다.

## 포트폴리오

- 시장국면별 배당주·성장주·현금 목표비중은 사용자 설정에서 관리한다.
- 종목 최대비중과 산업 최대비중은 전체 포트폴리오 공통 한도로 적용한다.
- 배분 순서는 그룹 우선순위, 핵심 투자매력, 진입준비, 데이터 신뢰도와
  종목코드로 결정해 동일 입력에서 동일 결과를 만든다.
- 각 활성 배당·성장 전략군은 목표 종목 수가 허용하면 최소 한 종목을
  먼저 선택하고, 종목 비중은 설정 한도를 넘지 않도록 내림 처리한다.
- 기업집단 코드가 확인되면 기업집단 한도를 적용한다. 현재 공식 writer가
  없어 `NOT_AVAILABLE`로 저장하고 사용자가 위험을 확인할 수 있게 한다.

## 분할매수와 보유 판단

- 기본 4회 비중은 config에서 관리하며 합계가 100%여야 한다.
- 각 회차에 실행 조건과 전체 취소 조건을 저장한다.
- 검증된 수정종가는 기준가격일 뿐 주문가격이 아니다. 검증된 지지구간이
  없으면 회차별 목표가격을 생성하지 않는다.
- 모든 계획은 읽기 전용이며 DB에서 `is_order_executable=false`를 강제한다.
- 투자배제 보유종목은 즉시 재검토, 데이터 부족은 판단 불가, 실제
  계산 비중이 종목 한도를 넘으면 부분 비중축소 검토로 표시한다.
- RSI 하나만으로 전량매도를 지시하지 않는다.

## 재현성

추천 실행에는 분석시각, 데이터 기준일, `score_version`, `rule_version`,
Phase 3 규칙 버전, config hash, 전체 입력 hash, 종목별 Phase 2 snapshot
hash, 시장 snapshot hash, 원시 지표, 필터 결과와 양방향 근거를 저장한다.
같은 기준시각·snapshot·config·버전이면 기존 추천 실행을 재사용한다.
검증 수정가격의 통화·수집시각·시세구분도 입력 hash와 분할매수
provenance에 포함하며, profile mapping은 key 순서와 무관한 canonical
hash를 사용한다.
