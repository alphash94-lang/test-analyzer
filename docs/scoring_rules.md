# Phase 2 점수 규칙

이 문서는 `phase2-rule-v2`의 실제 구현을 설명한다. 임계값과 가중치는
`app/config.py`의 `PHASE2_*` 환경변수로 변경할 수 있으며, 실행 결과에는
`score_version`, `rule_version`, 입력 데이터 해시를 함께 저장한다.

## 계산 순서

1. 강제필터를 모두 계산한다.
2. 하나라도 `FAIL`, `MISSING`, `REVIEW_REQUIRED`이면 투자매력 점수를
   계산하지 않는다.
3. 모든 강제필터 통과 후 배당·재무·밸류에이션 구성요소를 계산한다.
4. 핵심 구성요소가 하나라도 없거나 적용 불가이면 낮은 점수를 만들지 않고
   투자매력 점수를 NULL로 유지한다.
5. 데이터 신뢰도는 별도로 계산한다. 기준 미달이면 점수가 있더라도
   추천 계산 불가다.

`recommendation_computable`은 Phase 2 입력 게이트 통과 여부다. 최종 추천
레코드 생성이나 후속 Phase 판정 완료를 뜻하지 않는다.

## 강제필터

| 코드 | 기본 규칙 |
|---|---|
| `MARKET_UNIVERSE` | 공식 KOSPI, 주식, 보통주, 상장 상태가 모두 확인돼야 통과 |
| `MARKET_STATUS` | 관리종목·거래정지·상장폐지 위험 공식 확인 범위가 있고 모두 거짓이어야 통과 |
| `AUDIT_OPINION` | 기본 365일 이내 적정의견, 계속기업 확인 상태 `VERIFIED`, 위험 없음 |
| `LIQUIDITY` | 최근 60일 중앙 거래대금 10억원 이상, 최근 20일 거래량 0 없음, 예정 주문금액이 최근 20일 중앙 거래대금의 0.5% 이하 |
| `CORPORATE_EVENT` | 공식 확인 범위에서 중대 사건·수동검토 사건 없음 |
| `FINANCIAL_RISK` | 비금융업은 반복 영업손실 2년 미만이어야 한다. TTM 이자보상 1배 미만은 지속 여부가 확인될 때까지 `REVIEW_REQUIRED`. 금융업은 별도 모형의 통과 결과가 없으면 `MISSING` |

이자비용이 0이고 영업이익이 음수가 아니면 0으로 나누지 않고
`LOW_DEBT`로 표시한다. 단일 TTM 이자보상비율만으로 “1배 미만 지속”을
확정하지 않으며, 금융업에는 이 규칙을 적용하지 않는다.

## Phase 2 핵심 투자매력

전체 프로젝트 기본 투자매력 100점 중 이번 Phase의 70점만 계산한다.
저장 범위는 `PHASE2_CORE_ONLY`이며, 아래 기여점 합계를 70으로 나눠
100점 척도로 정규화한다. 후속 Phase 30점을 0으로 채우지 않는다.

### 배당 지속가능성 25

| 구성요소 | 가중치 | 정규화 |
|---|---:|---|
| 최근 5년 배당 연속성 | 10 | 연속된 최근 5개 사업연도 중 확정 DPS가 양수인 연도 비율 |
| DPS 안정성 | 5 | 4개 연도 전환 중 DPS 비삭감 구간 비율 |
| 배당성향 | 5 | 현금배당총액/지배기업 소유주지분 TTM 순이익. 70% 이하 100점, 120% 이상 0점, 사이 선형 |
| FCF 배당성향 | 5 | 현금배당총액/(영업현금흐름-유형 CAPEX-무형 CAPEX), 동일 구간 |

지배기업 순이익 또는 FCF가 0 이하인 경우 정상 비율로 표시하지 않고
해당 위험 구성요소만 0점으로 처리한다. 입력 누락은 0점이 아니라
`MISSING`이다.

### 비금융업 재무건전성 25

| 구성요소 | 가중치 | 정규화 |
|---|---:|---|
| TTM 영업이익률 | 6.25 | 0%에서 0점, 20%에서 100점 사이 선형 |
| ROE | 6.25 | 지배기업 순이익/지배기업 자본, 0%에서 0점, 15%에서 100점 |
| 부채비율 | 6.25 | 부채/지배기업 자본, 50% 이하 100점, 200% 이상 0점 |
| 현금전환 | 6.25 | 영업현금흐름/지배기업 순이익, 0에서 0점, 1 이상 100점 |

금융업에는 이 네 구성요소를 적용하지 않는다.

### 산업·자체 역사 밸류에이션 20

| 구성요소 | 가중치 |
|---|---:|
| 산업 PER | 6 |
| 산업 PBR | 6 |
| 자체 역사 PER | 4 |
| 자체 역사 PBR | 4 |

- PER/PBR은 양수 값만 유효 표본으로 사용한다.
- IQR 1.5배 범위 밖 극단값을 제외하되 결과가 비면 원 표본을 유지한다.
- 세부 산업 유효 표본이 기본 10개 미만이면 상위 산업을 사용한다.
- 상위 산업도 최소 표본 미달이면 `MISSING`이다.
- 자체 역사는 기본 최소 3개, 최대 최근 5개 값을 사용한다.
- 현재 값이 0 이하이면 `N/M`이며 기여점을 만들지 않는다.
- 정규화는 `기준 중앙값/현재값`이 0.75 이하일 때 0점,
  1.50 이상일 때 100점, 사이는 선형이다.

## 데이터 신뢰도 100

| 구성요소 | 가중치 |
|---|---:|
| 필수 입력 완전성 | 20 |
| 최신성 | 15 |
| 공식 출처 비율 | 15 |
| 교차검증 | 10 |
| 산업 유효 표본 | 15 |
| 수정가격 확인 | 10 |
| 재무 계정 매핑률 | 15 |

최신성은 핵심 데이터 최대 경과일 90일까지 100점, 365일 이상 0점으로
선형 처리한다. 데이터 신뢰도 기본 기준은 70점이다. 신뢰도는 예상
수익률이나 추천 확률이 아니다.

산업 표본은 단순 peer 수가 아니라 양수 PER와 PBR을 모두 비교할 수 있는
유효 표본 수의 보수적인 최소값을 사용한다.

## 개별 종목 진입 구성요소

전체 진입준비 100점 중 이번 Phase의 종목 추세·RSI 20점만 계산하고
`individual_entry_score`로 100점 척도 정규화한다. 전체 `entry_score`는
NULL이다.

- 모든 가격 입력은 단일 원천의 수정가격 `VERIFIED`여야 한다.
- RSI 40~60은 100점, 30~40 또는 60~70은 70점, 80 이상은 0점,
  나머지는 30점이다.
- 종가 ≥ SMA20 ≥ SMA60은 100점, 종가 ≥ SMA20은 70점,
  그 외는 30점이다.

## 저장 근거

각 결과에는 다음을 저장한다.

- 통과·실패·누락 강제필터와 사유
- 구성요소 상태, 원시값, 정규화값, 가중치, 기여점, 설명
- 현재 값, 산업·역사 중앙값, 백분위, 비교 수준, 표본 수
- 누락된 핵심 데이터
- 점수·규칙 버전과 입력 데이터 해시
- 기준시각과 데이터 상태
