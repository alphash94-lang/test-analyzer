# 데이터 소스 매트릭스

## 1. 상태 정의

이 문서의 `분류`는 다음 값 중 하나만 사용한다.

- `공식 API에서 직접 제공`: 공식 endpoint와 해당 데이터 필드 또는 기능 계약을 확인했다.
- `공식 원문 파싱 필요`: 공식 공시·문서 원본은 받을 수 있지만 필요한 값을 별도로 해석해야 한다.
- `직접 계산 가능`: 확인된 원자료가 있으면 결정론적 계산으로 만들 수 있다.
- `별도 계약 또는 권한 필요`: 공개 API 범위를 벗어나거나 자동·대량 이용에 별도 승인이 필요하다.
- `현재 확인 불가`: 공식 기능명 또는 요구는 있으나 endpoint·필드 계약이나 제공 여부를 확정하지 못했다.
- `MVP 보류`: 공식 원자료 가능성과 별개로 초기 분석에 필수가 아니거나 품질모형이 별도로 필요한 항목이다.

`공식 API에서 직접 제공`은 현재 환경에서 실제 호출에 성공했다는 뜻이 아니다. 모든 인증형 API 연결은 키 미설정으로 `연결 미검증`이다.

## 4. Phase 0A 이후 사용 금지

- `현재 확인 불가`, `별도 계약 또는 권한 필요`, `MVP 보류` 항목을 운영 추천 입력으로 사용하지 않는다.
- `공식 API에서 직접 제공`이어도 실제 응답 스키마와 단위를 검증하기 전에는 `NOT_VERIFIED`다.
- KIND 화면 내부 요청, 비공개로 보이는 경로, 브라우저 개발자도구에서 관찰한 호출을 공식 endpoint로 등록하지 않는다.
- KRX·KIS에서 단위가 명시되지 않은 숫자를 관례만으로 원·주·백만원 등으로 확정하지 않는다.
